`+0.260 us` final kernel-to-collective time. The active root cause is therefore
host replay invocation scheduling before `mcGraphLaunch`, not MCCL transfer,
launch API duration, or late-rank device execution.

## Metric Contract

For steady decode step `s`, collective ordinal `i`, and rank `r`, first match
the semantically identical GPU graph-parent range on every rank. Use its start
as a per-rank local anchor:

```text
anchor[s,r]          = matched GPU graph-parent start
relative_start[s,i,r] = collective start - anchor[s,r]
relative_end[s,i,r]   = collective end - anchor[s,r]
arrival_skew[s,i]     = max(relative_start) - min(relative_start)
completion_tail[s,i]  = max_r(max(0, relative_end[r] - max(relative_start)))
residency[s,i,r]      = end - start
pre_gap[s,i,r]        = start - end(previous device event on the same rank/stream)
late_rank_candidate   = rank with maximum relative_start
```

Subtracting a same-rank graph anchor removes constant cross-process clock
offsets while retaining accumulated rank-local compute and scheduling skew
inside the matched decode graph. Require identical graph-parent semantics,
collective counts, and collective ordinals across ranks. If graph parents
cannot be matched, the run is inconclusive.

Residency asymmetry remains supporting evidence only. It may show that some
ranks wait longer, but it cannot identify arrival order or route a plan by
itself.

Cross-rank absolute timestamps are optional corroborating evidence. Use them only when
all four traces expose the same absolute profiler clock metadata and a shared
calibration marker proves residual offset `<=2 us`. Under that condition:

```text
arrival_skew = max(start) - min(start)
completion_tail = max_r(max(0, end[r] - max(start)))
```

If calibration is absent or fails, report absolute start/end alignment as
unavailable and continue with graph-anchor-relative metrics; never route from
uncalibrated absolute timestamps.

Also record the preceding operator category for every rank:

```text
MHC | MoE | attention | memcpy | graph/host gap | other
```

Do not sum overlapping asynchronous parent and child events. Match collectives
only when all four ranks have the same steady-step and ordinal counts.
